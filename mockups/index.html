Ce que ces maquettes montrent — et ce qu'elles ne montrent pas

Elles illustrent le design system proposé (section 5 du document) : palette et ombres unifiées, icônes Bootstrap Icons à la place des émojis, mode sombre natif Bootstrap 5.3, cartes et tableaux restylés. Les données affichées sont fictives.

Elles ne sont pas branchées à Flask ni à Jinja2 : ce sont de simples fichiers HTML statiques pour juger du rendu. Aucune route, aucun gabarit de l'application n'a été modifié. Bootstrap et les icônes sont chargés depuis un CDN uniquement pour cette maquette ; l'implémentation réelle (Phase 1) les auto-hébergera dans static/vendor/ comme prévu dans le document de cadrage.
